---

## 🚀 Як встановити переклад

### Варіант 1: Через LBK Launcher (Рекомендовано) 🌟
Найпростіший спосіб встановлення в один клік:
1. Завантажте та встановіть лаунчер: [LBK Launcher](https://lbklauncher.com).
2. Знайдіть **The Guild 3** у списку ігор.
3. Натисніть кнопку **«Встановити»** навпроти української локалізації.

### Варіант 2: Через Steam Workshop (Якщо доступно) 🔵
*Якщо ви завантажили мод у майстерню, додайте інструкцію сюди:*
1. Підпишіться на мод у Steam Workshop: **[Посилання](https://steamcommunity.com/sharedfiles/filedetails/?id=3507960492)**
2. Переконайтеся, що мод увімкнено в налаштуваннях гри.

### Варіант 3: Встановлення вручну ⚙️
1. Завантажте архів з розділу **[Releases](посилання)**.
2. Скопіюйте вміст папки `build` у корінь гри із заміною файлів.
   * *Шлях для Steam:* `...\Steam\steamapps\common\The Guild 3\Media\Localization\` *(уточни точний шлях до папки Localization у грі)*.

## 🤝 Як допомогти проекту

Оскільки переклад уже готовий, робота над ним полягає в **редактурі та виправленні помилок**. 

Якщо під час гри ви помітили:
* Одруки, граматичні помилки чи вихід тексту за межі інтерфейсу.
* Неправильний контекст (наприклад, назва будівлі чи посади перекладена некоректно).

Будь ласка, створіть **[Issue](https://github.com/EYELESS-UA/The-Guild-3-Ukrainian-Localization/issues)** із описом проблеми та, бажано, скріншотом. Якщо ви знаєте, як виправити це в коді — створюйте **Pull Request** у папку `src/translation/`.
